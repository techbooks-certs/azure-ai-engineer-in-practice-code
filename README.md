# Azure AI Engineer in Practice — Companion Code

This repository is the reader companion to **Azure AI Engineer in Practice: Build GenAI Solutions and Pass the AI-103 Certification**.

## What is in this repository

The chapter files reproduce the **code blocks printed in Chapters 1–7 of the book, in book order**. They are provided here so you can use GitHub's Copy button instead of retyping code from the printed or Kindle edition.

## Important: how to use the snippets

The book builds one system progressively. A later snippet can depend on variables, imports, Azure resources, or functions established earlier in the same chapter or in an earlier chapter. Therefore:

1. Read the corresponding section in the book first.
2. Copy the code block from the matching chapter file here.
3. Replace placeholders such as `<sub-id>`, resource names, endpoints, regions, or deployment names with values from your own Azure environment.
4. Follow the book's explanation of prerequisites, RBAC, quota, regional availability, and cleanup.
5. Azure services can incur charges. Do not provision resources you do not understand, and delete lab resources when finished.
