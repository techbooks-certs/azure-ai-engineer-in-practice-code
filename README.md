# Azure AI Engineer in Practice — Companion Code

This repository contains the companion code examples for **Azure AI Engineer in Practice: Build GenAI Solutions and Pass the AI-103 Certification** by Edmund Ashcombe.

The chapter files follow the code blocks in Chapters 1–7 in book order. Use GitHub's Copy button to avoid retyping examples from the paperback or Kindle edition.

## How to use the examples

1. Read the corresponding section of the book for context and prerequisites.
2. Work through the examples in chapter order; later snippets may depend on variables or resources created earlier.
3. Replace subscription IDs, deployment names, endpoints and other placeholders with values from your own Azure environment.
4. Check roles, quotas, region availability and SDK or API versions for your subscription before executing examples.
5. Azure resources may incur charges. Follow the book's cleanup guidance and delete resources you no longer need.

Some blocks show example output or fragments for illustration; they are not independent programs. The book explains the surrounding workflow.
